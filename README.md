## 📖 Overview

**Influencer Weds Marketing** is an award-winning modern agency platform bridging premier brands and creators across India. Built with editorial visual storytelling, tactile creator collages, yellow brush-stroke annotations, cinematic typography, and high-performance micro-interactions.

### 🎯 Key Highlights & Architecture
* **Cinematic Preloader:** 12-frame coordinated animation sequence with crown emblem, image scatter & gather, keyword reveals, progress indicator, and skip control.
* **Hero Experience:** Editorial polaroid overlays, dynamic creator spotlight, live engagement metrics, and social proof counter.
* **Services Grid:** Detailed offerings spanning Influencer Collaborations, High-Converting Digital Campaigns, Creative Content Production, and ROI Campaign Management.
* **Interactive Portfolio:** Filterable showcase across Fashion & Beauty, Tech & Gadgets, Travel, Lifestyle, and Food & Beverage.
* **Process Roadmap:** Step-by-step 4-phase campaign execution model (Discovery, Creator Matching, Creative Production, Optimization).
* **Lead Conversion Engine:** Interactive consultation booking and creator onboarding form with instant unique reference tracking ID.
* **Performance-First:** Complete WebP image pipeline, lightweight vector iconography, lazy loading, and sub-second load times.

## 🚀 Getting Started

### Prerequisites
* Node.js 18+
* npm or pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/infinity1306/influencer-weds-marketing.git

# Navigate to project folder
cd influencer-weds-marketing

# Install dependencies
npm install

# Start local dev server
npm run dev
```

Visit `http://localhost:5173` to explore the site locally.

### Production Build

```bash
# Typecheck and build for production
npm run build

# Preview production build locally
npm run preview
```
